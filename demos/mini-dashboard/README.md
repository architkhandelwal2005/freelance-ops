# Nila Studio request dashboard (fictional demo)

Open `index.html` in a browser. Two fictional rows appear. Add a request, search by name, filter by status, edit a row and delete one after confirmation. The page stores data in browser `localStorage`; it has no login and must never hold real client data.

For a paid tool, Claude must provide users, roles, retention rules, private hosting and a backup requirement. Those inputs determine the backend and authentication design.

**60-second walkthrough:** show the initial rows, add a request, filter to New, edit its status, then search for it and explain local-only storage.
