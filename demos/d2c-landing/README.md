# Tamarind Trail landing page (fictional demo)

Open `index.html` in a browser. The page has a hero, benefit cards, a clearly labelled social-proof slot, on-page FAQ with matching FAQPage structured data, and a sticky purchase-action preview. The button explains that no checkout exists and never takes payment.

The concept uses original CSS illustration and no third-party asset. The brand, products and testimonials are fictional; there are no performance or health claims. A client version needs approved product facts, brand assets, consent for reviews and a real checkout link.

**60-second walkthrough:** show the mobile layout, scroll through benefits and FAQ, press the sticky CTA, then inspect the FAQ structured data in the page source.
