# Astro static landing-page starter

Run `npm install` then `npm run build`; the static site appears in `dist/`. Astro is a site builder that outputs ordinary HTML by default. The dependency is pinned to 7.4.4, checked against the package registry on 29 October 2026; Node 22.23.4 or newer is required.

Replace the fictional brand, title, copy and contact route with Claude-approved material. Add client assets only with permission. Run mobile, keyboard, link and Lighthouse checks before asking Claude to review. Publish only with written live-site go-ahead in the job file.
