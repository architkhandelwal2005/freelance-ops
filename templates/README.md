# Delivery templates

Use these only with an assigned job file and the matching `.agents/skills/` guide. Replace fictional facts and placeholders with Claude-approved inputs. Work on a copy or staging site and send the finished pack to Claude for review.

- `landing-page-starter/`: Astro static page starter.
- `shopify-sections/`: hero, FAQ with schema, sticky cart action and merchant-approved store statements.
- `wordpress-fixes-checklist.md`: staging, backup, repro, fix and rollback checks.
- `automation/`: form to Sheet and alert, email to summary/task, official WhatsApp enquiry to CRM designs.
- `geo-toolkit/`: organisation schema and llms.txt generators, crawl template, FAQ prompt and visibility checklist.
- `handover/`: client checklist, backup/restore record and before/after report.
