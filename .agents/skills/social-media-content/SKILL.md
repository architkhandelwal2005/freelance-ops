# social-media-content

Use with `delivery-standards` for any assigned paid job. Work from Claude's job file, not from assumptions.

## Intake
Require Audience, platform, themes, approved facts/assets, dates, voice and approval workflow. If a field is absent, put the precise question in the job file under `## Questions` for Claude. Do not fill missing client facts from search.

## Method and default stack
Default no-cost stack: CSV calendar, SVG graphics and Markdown copy; existing Canva only if already available.

1. Define content pillars and cadence from the brief.
2. Draft calendar with format, objective and source per post.
3. Create reusable card/carousel visual system.
4. Write captions and alt text without invented proof.
5. Check dimensions, scheduling dates and approvals.

## Time guide
Small 3-6 h; medium 1-2 days; large 3-5 days for a month. These are internal effort guides, not client commitments.

## QA: pass criteria
- [ ] Calendar has date, channel and objective.
- [ ] All claims source-checked.
- [ ] Graphics readable on phone.
- [ ] Alt text and CTA present.
- [ ] No post scheduled or published without Claude.

Save the evidence in the job folder; a claim of "tested" without results does not pass. Use [checklist.md](checklist.md) to record the checks.

## Deliverables and handover pack
Calendar CSV, editable graphics, captions, alt text, source log and walkthrough script. Include a plain-language `handover.md` with run/update steps, files, limits, backup location and a 60-second walkthrough script.

## Escalate to Claude when
Publishing request, unapproved claim, paid design asset or new channel. Record the question in the job file and stop the dependent action.

## Never
Never contact anyone or send client-facing work directly; Claude reviews and delivers. Never spend money or sign up as Archit; use no-cost tools first. Never invent clients, claims, results or experience; mark unknowns [TO CONFIRM]. Describe Archit as building with AI tools and checking every change by hand, never as hand-coding. Never confirm price, deadline or scope. Back up sites and work only on staging without written live-production go-ahead. Keep client data private; public samples use fictional brands. Do not put “free” in client-facing copy. Do not make unsupported medical, legal or financial claims.

For a fictional test brief, use [prompt.md](prompt.md).
